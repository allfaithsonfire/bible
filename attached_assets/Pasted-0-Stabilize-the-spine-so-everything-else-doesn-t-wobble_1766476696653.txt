1) Discord login (everyone has an identity, even if anonymous to the public)

1.1 OAuth: Discord sign-in

Add “Sign in with Discord”

Store a user record (create a users table if you don’t already have one in code):

id (pk), discord_id (unique), username, avatar, created_at, last_login_at

1.2 Roles

Add user_roles (or user_role) table:

role: admin, moderator, author, reader (default)

Done when: clicking “Contribute” forces login; after login you return to where you were; role gates work.
